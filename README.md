# Claude Code Experiments Repository

## Purpose
This repository serves as an experimental sandbox for testing Claude Code capabilities. It contains various experiments, proof-of-concepts, and learning exercises conducted through conversational AI-assisted development.

## Repository Structure & Conventions

### For Claude Code
When working in this repository, you should:

1. **Create Feature Branches for Each Experiment**
   - Branch naming: `experiment/<experiment-name>`
   - Each experiment lives in its own branch to keep work isolated

2. **Organize Each Experiment**
   - Create a dedicated directory: `/experiments/<experiment-name>/`
   - Include an experiment-specific README.md explaining:
     - What the experiment tests/demonstrates
     - How to run it
     - Key learnings or findings
     - Dependencies and setup instructions

3. **Main Branch**
   - Keep main branch clean
   - Use it only for this root README and general repo documentation

4. **Documentation**
   - Document as you go
   - Capture interesting findings, gotchas, and insights
   - Include code comments explaining non-obvious decisions

### Workflow
1. **Chris describes an experiment in chat**
2. Claude creates a feature branch: `experiment/<experiment-name>`
3. Claude builds the experiment in `/experiments/<experiment-name>/`
4. Claude documents the process and results

---

**Note**: This is a learning and experimentation space. Code here may be rough, incomplete, or exploratory. The goal is rapid iteration and learning, not production-ready code.
