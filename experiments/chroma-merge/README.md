# Chroma Merge - Research-Driven iOS Game Experiment

> A hybrid-casual sorting-merge puzzle game with color-mixing mechanics. Built using data-driven insights from 2024-2025 mobile gaming research.

## 🎯 Executive Summary

**Chroma Merge** combines proven monetizable game mechanics (sorting puzzles + merge + idle) with a novel twist: **dynamic color mixing**. Unlike existing sorting games (Hexa Sort, Block Jam 3D), adjacent colors MIX when placed together, creating puzzle complexity and educational value through color theory discovery.

**Target ARPDAU**: $5-7 (idle/merge games average 9x hypercasual revenue)
**Monetization Model**: Hybrid (IAP primary + Rewarded Ads + Subscription)
**Genre**: Hybrid-Casual Puzzle
**Platform**: iOS (SwiftUI)

## 💡 Why "Chroma Merge" is Novel

### Market Gap Analysis

**Existing Sorting Games:**
- Hexa Sort, Block Jam 3D, Twisted Tangle
- Mechanic: Sort static objects into containers
- **Limitation**: No interaction between objects

**Existing Merge Games:**
- Focus on object progression (merge 2 items → better item)
- Themes: Gardens, buildings, creatures
- **Limitation**: Limited educational value

**Musical Merge Games:**
- Tune Town, Midas Merge (discovered in research)
- Music is a **theme/setting**, not core mechanic
- **Limitation**: Not focused on creation/synthesis

### Chroma Merge's Innovation

✨ **Dynamic Color Mixing as Core Mechanic**
- Colors MIX when adjacent (unique to sorting genre)
- Creates puzzle complexity: unmixing challenges
- Educational angle: Color theory discovery
- Variable outcomes: Same colors + different order = different results

✨ **Triple Threat Mechanics**
- **Sorting**: Align with #1 trend
- **Merge**: High IAP conversion
- **Idle**: 9x ARPDAU potential

✨ **Collection Psychology**
- 16 discoverable colors (primary → tertiary → special)
- ColorPedia tracking (gotta catch 'em all)
- Rarity system (common → legendary)

## 🎮 Core Gameplay Loop

### 1. Game Start
Player receives 4-8 containers with mixed colored orbs

### 2. Core Mechanic
- Tap container to select
- Tap another container to move top orb
- **If colors are mixable → They MIX** (unique!)
- **If colors match → Stack normally** (sorting)

### 3. Color Mixing Rules (Color Theory)
```
Primary + Primary = Secondary
  Red + Yellow = Orange
  Yellow + Blue = Green
  Blue + Red = Purple

Primary + Secondary = Tertiary
  Red + Orange = Red-Orange
  Yellow + Orange = Yellow-Orange
  ...and more

Complex Mixes = Brown/Gray
```

### 4. Win Condition
- Sort all containers to pure colors
- OR create target color combinations
- Complete with fewest moves for bonus gems

### 5. Progression
- Unlock new colors (primary → secondary → tertiary → special)
- Increase difficulty (more colors, smaller containers)
- Level up player account (earn permanent gem bonuses)

### 6. Idle Mechanics
- Colors slowly "separate" when offline
- Return to collect gems from idle progress
- Push notifications: "Your colors are ready!"

**Simplicity Meets Depth**
- Easy to learn (tap, drag, merge)

- Beautiful (color-focused aesthetics)
- Educational (color theory discovery)

**Monetization with Respect**
- Never pay-to-win
- Ads are optional (rewarded)
- Premium feels premium
- Fair pricing ($1-5 sweet spot)

**Player-First**
- No dark patterns
- Clear value propositions
- Generous free experience
