# AI Bookmark Organizer - Chrome Extension

## Overview
An intelligent Chrome extension that replaces the traditional bookmark system with AI-powered organization. Uses OpenRouter AI to analyze and categorize bookmarks automatically, with conversational feedback for refined organization.

## What This Experiment Tests/Demonstrates
- Chrome Extension API integration (bookmarks, storage)
- AI-powered content analysis and categorization using OpenRouter
- Vector embeddings with pgvector for semantic search
- Real-time chat interface for AI-human collaboration
- Full-stack application: Chrome Extension + Node.js Backend + PostgreSQL

## Problem Solved
Traditional bookmark management requires manual organization, leading to:
- Disorganized bookmark collections
- Difficulty finding saved content
- Time wasted on manual categorization

This extension uses AI to:
- Automatically suggest bookmark organization based on content analysis
- Learn from user feedback to improve suggestions
- Enable semantic search across bookmarks
- Provide conversational interface for bookmark management

## Architecture

### Components
1. **Chrome Extension** (`/extension`)
   - Popup UI for bookmark access and search
   - Background service for bookmark interception
   - Options page for configuration
   - Content scripts for page analysis

2. **Backend API** (`/backend`)
   - Express.js REST API
   - OpenRouter AI integration
   - PostgreSQL + pgvector for storage
   - Embedding generation and semantic search

3. **Database** (`/database`)
   - PostgreSQL with pgvector extension
   - Bookmark storage with embeddings
   - Category/tag management
   - User preferences

## Features

### Core Functionality
- **Intelligent Bookmark Capture**: When you bookmark a page, AI analyzes the content
- **Smart Organization**: AI suggests categories based on existing bookmarks
- **Conversational Refinement**: Chat with AI to adjust organization
- **Dual Search**:
  - Traditional keyword search
  - AI semantic search using vector embeddings
- **Category Management**: Auto-generated and user-defined categories

### Configuration
- OpenRouter API key
- Model selection (configurable)
- Database connection settings
- Organization preferences

## Setup Instructions

### Prerequisites
- Node.js 18+ and npm
- PostgreSQL 14+ with pgvector extension
- Chrome browser
- OpenRouter API key (https://openrouter.ai/)

### Database Setup

1. Install PostgreSQL and pgvector:
```bash
# Install PostgreSQL (if not already installed)
# For Ubuntu/Debian:
sudo apt-get install postgresql postgresql-contrib

# Install pgvector
cd /tmp
git clone https://github.com/pgvector/pgvector.git
cd pgvector
make
sudo make install
```

2. Create database:
```bash
cd database
psql -U postgres -f schema.sql
```

3. Set environment variables:
```bash
export DATABASE_URL="postgresql://username:password@localhost:5432/bookmarks_ai"
```

### Backend Setup

1. Install dependencies:
```bash
cd backend
npm install
```

2. Configure environment:
```bash
cp .env.example .env
# Edit .env with your settings:
# - DATABASE_URL
# - OPENROUTER_API_KEY (optional, can be set in extension)
# - PORT (default: 3000)
```

3. Start server:
```bash
npm start
```

### Chrome Extension Setup

1. Build extension (if needed):
```bash
cd extension
# No build step required - pure HTML/CSS/JS
```

2. Load in Chrome:
   - Open Chrome and go to `chrome://extensions/`
   - Enable "Developer mode"
   - Click "Load unpacked"
   - Select the `/extension` directory

3. Configure extension:
   - Click extension icon → Options
   - Enter your OpenRouter API key
   - Select AI model (default: anthropic/claude-3.5-sonnet)
   - Enter backend URL (default: http://localhost:3000)

## Usage

### Bookmarking a Page
1. Click the bookmark icon (Ctrl/Cmd+D) or use the extension popup
2. AI analyzes the page content
3. AI suggests a category/folder based on existing bookmarks
4. Chat with AI to refine the organization if needed
5. Confirm to save

### Searching Bookmarks
1. Open extension popup
2. Use search bar:
   - Type normally for keyword search
   - Prefix with "/" for AI semantic search
   - Example: "/articles about machine learning"

### Managing Categories
- Categories are auto-generated by AI based on content clustering
- You can rename, merge, or delete categories in the popup
- AI learns from your organizational preferences

## API Endpoints

### Bookmarks
- `POST /api/bookmarks` - Create bookmark with AI analysis
- `GET /api/bookmarks` - List all bookmarks
- `GET /api/bookmarks/search` - Search bookmarks (keyword)
- `POST /api/bookmarks/search/semantic` - AI semantic search
- `PUT /api/bookmarks/:id` - Update bookmark
- `DELETE /api/bookmarks/:id` - Delete bookmark

### Categories
- `GET /api/categories` - List all categories
- `POST /api/categories` - Create category
- `PUT /api/categories/:id` - Update category
- `DELETE /api/categories/:id` - Delete category

### AI
- `POST /api/ai/analyze` - Analyze page for categorization
- `POST /api/ai/chat` - Chat with AI about bookmarks
- `POST /api/ai/suggest` - Get organization suggestions

## Technical Details

### AI Integration
- Uses OpenRouter API for model flexibility
- Generates embeddings for semantic search (text-embedding-ada-002 or similar)
- Analyzes page title, URL, content, and meta tags
- Compares against existing bookmark embeddings

### Vector Search
- pgvector stores 1536-dimensional embeddings
- Cosine similarity for semantic matching
- Hybrid search: combines keyword + semantic results

### Data Flow
1. User bookmarks page → Extension captures metadata
2. Extension sends to backend API
3. Backend fetches page content (if needed)
4. AI analyzes content and generates embedding
5. AI compares with existing bookmarks (vector similarity)
6. AI suggests category and explains reasoning
7. User can chat to refine
8. Bookmark stored with embedding in PostgreSQL

## Key Learnings

### Challenges
- Chrome extension security model (CORS, CSP)
- Balancing AI API costs with functionality
- Real-time chat UI in extension popup
- Efficient vector search with large bookmark collections

### Solutions
- Backend API as proxy for AI requests
- Caching embeddings and AI responses
- WebSocket or polling for chat updates
- Indexing strategies for pgvector
